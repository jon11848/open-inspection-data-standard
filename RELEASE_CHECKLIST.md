# Release Checklist

- [ ] Confirm version in schemas, examples, specification, and changelog.
- [ ] Run `python scripts/validate.py`.
- [ ] Confirm all examples validate and all internal references resolve.
- [ ] Review required-field changes for backward compatibility.
- [ ] Review privacy, security, and intellectual-property implications.
- [ ] Record material decisions under `decisions/`.
- [ ] Publish draft release notes and review period.
- [ ] Create a signed Git tag.
- [ ] Archive the exact schemas, API file, examples, and specification.
- [ ] Do not label a release final or certified without satisfying governance and conformance requirements.
