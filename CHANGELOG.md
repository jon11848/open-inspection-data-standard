# Changelog

## [0.1.0] — 2026-07-30

### Added

- Initial asset-centered conceptual model.
- Separate Observation, Finding, and Issue entities.
- Location, evidence, actor, inspection program, inspection event, relationship, taxonomy, profile, lifecycle event, and package schemas.
- OpenAPI description of standard API behaviors.
- CloudEvents-compatible lifecycle event catalog.
- Facade and building-envelope starter profile and example package.
- Interim governance, contribution, licensing, security, and release documents.
