# JSON Schemas

These schemas use JSON Schema Draft 2020-12 and provisional URN identifiers in the form `urn:oids:schema:<name>:0.1.0`. Relative `$ref` values allow local validation without a hosted schema registry.

Before Version 1.0, the project should establish a permanent controlled namespace and a resolvable release archive. The URN vocabulary identifiers used in examples are similarly provisional but stable within this draft.

The core required fields are intentionally small. Inspection profiles may impose additional requirements.
