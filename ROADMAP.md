# Roadmap

## Version 0.1 — Initial public working draft

- Publish core model, schemas, API behaviors, event catalog, sample package, and facade profile.
- Recruit founding design partners.
- Collect vendor mappings and at least three real inspection use cases.
- Establish an initial technical steering committee.

## Version 0.2 — Mapping and implementation draft

- Resolve findings from vendor mappings.
- Add import/export implementation guidance.
- Expand conformance tests and error examples.
- Add at least one non-building constructed-asset example.
- Add a second inspection profile.

## Version 0.3 — Interoperability pilot

- Demonstrate exchange among at least three independent systems or implementations.
- Test round-trip preservation of identifiers, relationships, locations, evidence metadata, and lifecycle state.
- Publish pilot results and unresolved incompatibilities.

## Version 0.5 — Governance and regulatory extension draft

- Transition to neutral multi-stakeholder governance.
- Publish regulator-facing submission, validation, comment, correction, and decision concepts as an extension.
- Define profile publication and registry rules.

## Version 1.0 — Candidate final standard

Target only after:

- two independent conforming implementations;
- a documented end-to-end interoperability test;
- stable identifier and versioning rules;
- a formal intellectual-property policy;
- neutral governance; and
- a public review period with resolved material objections.
