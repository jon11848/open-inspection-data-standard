# Facade Inspection Example

This synthetic package demonstrates:

- a building asset and recurring inspection program;
- a completed inspection event;
- address, drawing, and image locations;
- normalized coordinates from 0 through 1;
- an annotation group represented by a parent Observation;
- a child Observation supported by a photograph;
- an AI-authored, human-reviewed Finding;
- separate severity dimensions; and
- an Issue generated from the Finding.

The referenced evidence files are intentionally not included. The checksums and package paths are illustrative.
