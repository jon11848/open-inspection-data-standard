# 1. Purpose and Scope

OIDS defines a canonical exchange model for inspection information concerning constructed assets. Version 0.1 prioritizes vendor-to-vendor interoperability and long-term portability.

The standard does not require vendors to use the canonical model internally. A conforming implementation maps its internal objects to and from OIDS while preserving the information required by its claimed conformance role.

Version 0.1 includes generic support for inspection evidence, observations, professional or machine-authored findings, corrective issues, locations, actors, review, nesting, recommended vocabularies, profiles, API behaviors, and lifecycle events.

Version 0.1 does not define a regulator's legal filing requirements, professional scope of practice, inspection methodology, acceptance criteria, authentication scheme, storage architecture, or user interface.
